# JEBG Industrial AI Support Assistant website

Static marketing website for JEBG AISA, including product videos, screenshots and an email enquiry form.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.

All media uses relative paths. No build step is required. The enquiry form opens the visitor’s configured email application; it does not send mail from a server.

## Update

Edit `index.html` or replace files in `media/`, then commit to `main`.
